ABOUT THIS PROJECT

這不只是一個網頁

專案目的

建立一個以 Minecraft 為主題的輕量知識網站，示範如何透過專案規範，讓 AI 能持續新增內容而不破壞既有風格與結構。

可延伸方向

未來可加入合成配方、地形、生態系、模型設計紀錄，甚至把研究筆記整理成 3D 模型製作參考資料。

技術方式

使用原生 HTML、CSS、JavaScript 與 JSON 資料，不需要安裝框架或後端服務，可直接部署至 GitHub Pages。
